# W. Maximum seed-registry maintenance rule

The registry must never be treated as a finished static list. Every day HYPE must be able to answer:

- which known makers are not directly monitored;
- which region/language has no healthy community/editorial coverage;
- which brand has no official social/support endpoint;
- which new exhibitor/retailer/reviewer appeared;
- which source is now inactive;
- which new domain/platform is producing unique early evidence;
- which source family is contributing zero useful evidence and can be demoted.

The maximum seed list is therefore **curated breadth + self-expanding discovery + measured blind spots**, not a frozen claim that every possible URL has been enumerated forever.
