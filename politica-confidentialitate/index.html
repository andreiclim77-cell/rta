Politica de confidentialitate

Aceasta politica explica in mod transparent ce date pot fi procesate cand este accesat ghid-rta.ro sau cand sunt folosite integrarile administrative asociate platformei.

Versiune: 10 septembrie 2026Operator: Clim AndreiAplicatie informativa 18+Fara cont de utilizator

1. Operator si contact

Serviciul Ghid RTA MTL - Smokee este administrat de Clim Andrei. Pentru intrebari privind confidentialitatea sau exercitarea drepturilor, contactul este andrei.clim77@gmail.com.

2. Ce date sunt procesate

  • Ghidul nu solicita crearea unui cont, nu primeste plati si nu contine formular de transmitere directa a datelor personale.
  • Furnizorii tehnici pot procesa automat adresa IP, tipul browserului, dispozitivul, pagina solicitata, data si ora, exclusiv pentru livrare, securitate si diagnostic tehnic.
  • Limba selectata, acceptul 18+ si copiile temporare ale catalogului pot fi pastrate local in browser, fara a crea un profil personal pe serverul ghidului.
  • Daca este acordata permisiunea de localizare, coordonatele sunt folosite pentru afisarea vremii locale si sunt transmise catre Open-Meteo. Ghidul nu le salveaza intr-o baza proprie.
  • Contorul public de vizite este furnizat de visitor-badge.laobi.icu si poate primi datele tehnice asociate unei cereri web.
  • Aplicatia Meta este folosita de administratorii paginii pentru publicarea de continut. Vizitatorii ghidului nu se autentifica prin aceasta aplicatie si nu sunt profilati de ghid.
  • Integrarea Google Ads API este folosita de administrator pentru obtinerea unor statistici agregate privind interesul de cautare pentru termeni, produse, modele sau categorii urmarite. Vizitatorii nu isi conecteaza conturile Google Ads si nu furnizeaza ghidului credentiale Google Ads.

3. Scopurile procesarii

Datele tehnice sunt folosite pentru functionarea si securitatea site-ului, pastrarea preferintelor locale, afisarea informatiilor solicitate, masurarea agregata a accesului si publicarea continutului asociat platformei. Datele obtinute administrativ prin Google Ads API sunt folosite pentru statistici agregate si analiza informativa, nu pentru profilarea vizitatorilor si nu pentru administrarea campaniilor publicitare ale acestora.

4. Google Ads API

Ghid RTA poate utiliza Google Ads API, inclusiv servicii de planificare a cuvintelor cheie, pentru a calcula sau afisa indicatori statistici agregati precum volume estimate de cautare. Accesul este gestionat exclusiv de operatorul platformei. Publicul nu primeste acces la credentialele API si nu este obligat sa autorizeze un cont Google Ads pentru a consulta rezultatele publice.

Indicatorii furnizati ori estimati de serviciile Google sunt prezentati ca date statistice ale sursei si nu ca date personale ale vizitatorilor, vanzari sau masuratori exhaustive ale pietei.

5. Servicii externe

Ghidul poate folosi sau trimite catre GitHub Pages, Cloudflare, Open-Meteo, visitor-badge.laobi.icu, Facebook/Meta, YouTube, Google Ads API si Smokee.ro. La deschiderea unui link extern sau utilizarea unui serviciu extern se aplica si politica serviciului respectiv. Ghidul nu vinde si nu inchiriaza date personale.

6. Pastrarea datelor

Datele locale raman in browser pana la stergerea lor de catre utilizator. Jurnalele tehnice si datele procesate de furnizorii externi sunt pastrate conform politicilor si termenelor proprii ale acestora. Evidentele tehnice ale colectarilor statistice pot fi pastrate pentru verificarea provenientei si integritatii datelor publicate, fara a crea profiluri ale vizitatorilor.

7. Drepturile persoanei vizate

In conditiile Regulamentului general privind protectia datelor, pot fi solicitate informatii, acces, corectare, stergere, restrictionare sau opozitie, atunci cand aceste drepturi sunt aplicabile. Solicitarile pot fi trimise la andrei.clim77@gmail.com. Instructiunile practice sunt disponibile si pe pagina Stergere date.

8. Continut destinat adultilor

Ghidul este destinat exclusiv persoanelor de cel putin 18 ani. Nu se urmareste colectarea intentionata a datelor minorilor.

Important: recomandarile si indicatorii au caracter informativ. Cumpararea si plata produselor se realizeaza pe site-urile comerciantilor, conform propriilor politici.

Privacy Policy

This policy explains what data may be processed when ghid-rta.ro or its administrative integrations are used.

Controller and contact

The service is operated by Clim Andrei. Privacy requests can be sent to andrei.clim77@gmail.com.

Data and purposes

No visitor account, payment or direct personal-data form is provided. Hosting and security providers may process standard technical request data. Language, age confirmation and temporary catalogue data may be stored locally in the browser. With browser permission, location coordinates are sent to Open-Meteo to display local weather and are not retained in the guide's own database.

Google Ads API

The site operator may use the Google Ads API, including keyword planning services, to obtain aggregated search-interest statistics for selected terms, products, models or categories. Public visitors do not connect their Google Ads accounts and are not provided with API credentials. This administrative integration is used for aggregated statistical analysis and not to manage visitors' advertising campaigns or profile website visitors.

Meta application

The Meta application is used by Page administrators to publish Page content. Website visitors do not sign in through the application and the guide does not create visitor profiles from Facebook data.

External services and rights

The service may interact with GitHub Pages, Cloudflare, Open-Meteo, visitor-badge.laobi.icu, Facebook/Meta, YouTube, Google Ads API and Smokee.ro. Their own policies apply when those services are accessed. Applicable privacy rights can be exercised through the contact above. See Data deletion instructions.
