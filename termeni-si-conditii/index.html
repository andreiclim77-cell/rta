2. Despre Ghid RTA

Ghid RTA este o platforma cu caracter informativ, care organizeaza, analizeaza si prezinta informatii si indicatori relevanti pentru domeniile acoperite de platforma. Anumite functionalitati pot utiliza date provenite din surse terte si servicii externe, inclusiv servicii furnizate de Google.

Informatiile afisate sunt destinate informarii si analizei si nu reprezinta o garantie privind evolutia viitoare a interesului public, a pietei, a cererii sau a performantei unui anumit produs, model, serviciu ori operator.

3. Utilizarea Google Ads API

Ghid RTA poate utiliza Google Ads API, inclusiv serviciile de planificare a cuvintelor cheie, pentru obtinerea unor informatii statistice si agregate privind interesul de cautare pentru anumite expresii, produse, modele, categorii sau subiecte.

Aceasta integrare este utilizata in scop de analiza statistica si informare. Accesul API este administrat de operatorul platformei. Vizitatorii Ghid RTA nu primesc credentiale Google Ads si nu isi conecteaza conturile Google Ads la functia publica de clasament.

Ghid RTA nu utilizeaza aceasta integrare pentru administrarea campaniilor publicitare ale vizitatorilor si nu efectueaza in numele acestora modificari ale campaniilor, anunturilor, bugetelor sau ofertelor publicitare.

Indicatorii proveniti din Google Ads sau Google Keyword Planner, inclusiv volumele medii lunare de cautare, reprezinta valori furnizate sau estimate de serviciile Google si trebuie interpretati ca indicatori statistici, nu ca masuratori exhaustive ale vanzarilor sau garantii ale cererii efective.

Clasamentele bazate pe aceste informatii se raporteaza la setul de produse, modele, termeni sau categorii urmarite si masurate de Ghid RTA.
